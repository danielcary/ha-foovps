# myvps

A Rocky Linux workspace with key-based SSH, Node.js 24, Express, the .NET 10 SDK,
Nginx, and Certbot. Read the Documentation tab for setup and usage.

Default host ports: SSH **2222**, HTTP **8000**, HTTPS **8443**.
Add your public SSH key in Configuration before connecting as user **vps**.
An Express example is available immediately at the HTTP port.
